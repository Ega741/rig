# Token page — живые комиссии PONS-запуска (запись об исполнении)

**Дата:** 2026-09-14. **Запрос пользователя:** «я скину CA, задача — в реальном времени на сайте смотреть, сколько в пуле фисов». Токен пользователь запускает сам через PONS; `PonsTreasury` для этого не нужен.

## Что сделано

- `web/src/chain/pons.ts` — чтение состояния запуска PONS V2 по адресу токена: фабрика (`getLaunchedToken`, `getLaunchFeePolicy`), кривая (резервы, порог graduation, несвипнутые комиссия и налог), fee-escrow (`balanceOf` / `balanceOfToken`), после graduation — хук (`pendingFees` / `pendingCreatorTax` по quote и по токену) и цена из `slot0` PoolManager через `extsload`. Плюс история из событий `CurveBuy` / `CurveSell` / `HookFeeCollected` с блока `TokenLaunched` (поиск назад кусками по 200k блоков — публичный RPC не тянет запрос «с нуля»).
- `web/src/app/pages/Token.tsx` — страница **Token**: «комиссии создателя, ждущие сбора» (escrow + кривая + хук в quote + хук в токене по текущей цене), «заработано с запуска», оборот, сделки, цена, капитализация, прогресс до graduation, контракты. Опрос каждые 3 с. Адрес токена: `?token=0x…`, `VITE_PONS_TOKEN` или поле ввода на странице (запоминается в localStorage).
- Конфиг: `VITE_PONS_TOKEN`, `VITE_PONS_RPC_URL` (по умолчанию публичный mainnet RPC), query `token`, `ponsRpc`.

## Проверено

- Юнит: poolId, сортировка валют, слот состояния пула, цена из sqrtPrice в обе стороны, доля создателя — 5 тестов.
- Mainnet (`PONS_TOKEN=0x… npx vitest run src/chain/__tests__/pons.mainnet.test.ts`): токен на кривой с котировкой USDG (`0x997c…ef04`), выпускник с ERC-20-котировкой (`0xd278…6591`, `poolId` подтверждён через `hook.launches(poolId).registered`), токен с котировкой ETH (`0x3200…f518`: 2 сделки, оборот 0.0353 ETH, комиссии сходятся с событиями).
- В браузере против mainnet: `$TULIP`, 5.6405 USDG в escrow, блок обновляется каждые 3 с.

## Найдено по ходу

- **Запуск на PONS может быть не против ETH**: `pairToken` бывает USDG или stock-токен. Первая версия модуля считала quote = ETH и для таких токенов давала цену 0 и неверный `poolId`. Теперь quote читается из `pairToken`, символ и decimals — из его контракта, сортировка валют — как в фабрике.
- **Escrow PONS ведётся на получателя, а не на токен**: «можно забрать сейчас» — сумма по всем запускам этого адреса. Подпись на странице это говорит.
- Публичный RPC: ~16 вызовов на опрос; при многих зрителях лучше `VITE_PONS_RPC_URL` с ключом Alchemy.
